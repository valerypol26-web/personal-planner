## 🚨 Troubleshooting Чек-лист

**Проблема: Bot не отвечает**
- [ ] Перепроверены TELEGRAM_BOT_TOKEN (скопировано заново)
- [ ] Перезагружен сервер
- [ ] Проверены логи (если локально)
- [ ] Поднят вопрос сервера на Railway/Heroku

**Проблема: Web App не открывается**
- [ ] Проверена ссылка WEBAPP_URL (правильный URL?)
- [ ] Проверено, что фронтенд развернут
- [ ] Очищена кэш браузера
- [ ] Проверены DevTools (F12) → Console на ошибки

**Проблема: Данные не сохраняются**
- [ ] Проверена MONGODB_URI (скопирована заново)
- [ ] Добавлен IP адрес в MongoDB Whitelist
- [ ] Проверены логи сервера
- [ ] Проверено соединение с БД

**Проблема: Долгая загрузка**
- [ ] Проверена скорость сети
- [ ] Проверены логи сервера (медленные запросы?)
- [ ] Optimized frontend (npm run build)
- [ ] Проверены размеры бандла
